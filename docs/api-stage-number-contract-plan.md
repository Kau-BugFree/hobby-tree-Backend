# 나무·활동 단계 번호 계약

API-18~25·29·33·39·50에서 성장 단계 번호는 0~5다. 0은 새 나무이며 5는 최고 단계다.
단계당 활동 수가 k일 때 n단계 해금 기준은 n×k다. 전체 단계 수는 6이다.
카탈로그 키 stageId로 활동 목록을 요청하고 개별 활동 절차의 stepNumber는 1부터 센다.

## 기존 기록과 재전송

시작 스냅샷과 완료·삭제 최초 응답의 저장 형식 v1은 역사적으로 단계 번호를 1~6으로 기록한다.
새 기록도 같은 v1 형식으로 저장한다. API-29·50은 재전송 시 v1 응답의 두 성장 단계 번호만
각각 1 낮춰 반환한다. 당시 시각·성장 수치·플래그를 보존하며 현재 나무 상태로 재계산하지 않는다.
API-27은 시작 시 캡처한 내용으로 응답하며 성장 단계 번호를 노출하지 않는다.

## 프론트 전환

- stageNumber, currentStageNumber, growth의 previousStageNumber/currentStageNumber는 그대로 표시한다.
- 단계 0도 표시하도록 null 여부를 검사한다. 누락을 1단계로 대체하지 않는다.
- 이미지 인덱스는 0~5다. 마지막 단계는 5이고 totalStages는 6이다.
- API-24에는 stageId를 보내며 잠금 상태는 로드맵의 state를 따른다.
- 이전 응답을 저장한 앱 캐시는 전환 시 무효화한다. 1~5는 두 규격에 모두 있어서 숫자로 판별할 수 없다.
